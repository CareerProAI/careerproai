# TalentAI — Project Submission

## Description

TalentAI is an AI-powered career platform that turns resume screening and job hunting into a data-driven process. It parses resumes (PDF/DOCX/TXT), scores ATS compatibility, and delivers skill-gap analysis in seconds. Its standout feature is real-time job aggregation from BDJobs and LinkedIn, each listing scored against your actual resume by an AI model via OpenRouter. Built on React 19, TypeScript, Express, and SQLite, TalentAI replaces generic keyword-matching with genuine AI reasoning — showing candidates not just *which* jobs fit, but *why*, closing the gap between applying and getting hired.
